CHAPTER QUEST - ANDROID APP PROJECT

This is the full Android project. An APK is built by Google's official Android tools, which
are not available in the workspace where this was made, so the APK itself is built by you in
one of these two ways. Neither needs coding.

OPTION A - GitHub (free, no installs, about 5 minutes)
 1. Make a free account at github.com and create a new repository (any name).
 2. Upload everything in this folder to it, including the hidden ".github" folder.
    (On github.com: Add file > Upload files. Drag the whole folder contents in.)
 3. Open the "Actions" tab. "Build APK" starts by itself (wait about 3 to 5 minutes).
 4. Open the finished run, scroll to "Artifacts", download "ChapterQuest-apk", unzip it.
 5. Send app-debug.apk to your phone and install it.
    Android will ask you to allow "Install unknown apps" for the app you opened it from.

OPTION B - Android Studio (on a computer)
 1. Install Android Studio (free, developer.android.com/studio).
 2. File > Open, choose this folder, wait for Gradle to finish syncing.
 3. Build > Build APK(s). The file is at app/build/outputs/apk/debug/app-debug.apk.

NOTES
 - This is a debug-signed APK. It installs fine on a phone. For the Play Store you would
   make a release build with your own signing key.
 - The app needs no internet and asks for no permissions. It reads PDFs through the
   phone's file picker.
 - The app files live in app/src/main/assets. Edit them there to change the app.
 - This project was written but not compiled in the workspace, so the first build is the
   first real test. If it fails, send me the error text and I will fix it.
